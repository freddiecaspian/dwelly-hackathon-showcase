# Dwelly Hackathon Showcase

A single public page showing what teams built at Dwelly's London AI Hackathon (10 October 2026): the best-of showreel, each lettings team's one-minute demo, what it does, and a link to its open-source repo.

**Why:** to share with people asking what AI agents can already do in a letting agency's front office (first use: Gabriel Adebiyi, Permira Services, 27-10-26).

**Status:** live on GitHub Pages, 27-10-26. Demo videos and code are the teams' own (Apache 2.0). Videos re-encoded to 720p; the full-resolution showreels live in the vault at `16. Resource Images/Dwelly Hackathon Showreel/`.
